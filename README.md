# Streaming Content Analysis - SQL Project

## Project Overview

This project analyzes streaming content data using SQL.

## Dataset

The dataset contains information about movies and TV content, including:

- Title
- Media Type
- Release Year
- Popularity
- Rating
- Vote Count
- Language
- Genre

## SQL Skills Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- AVG
- MIN
- MAX
- SUM
- ROUND
- HAVING
- BETWEEN
- NULL checking
- Duplicate checking
- JOIN

## Analysis

The project analyzes:

- Overall content statistics
- Ratings
- Popularity
- Movie vs TV content
- Release years
- Languages
- Highly rated content
- Popular content
- Duplicate records
